# Purchases

A minimalist, editorial-style digital garden for recording shopping experiences and analyzing consumerism traps.

## Features

- **Minimalist Design**: Inspired by high-end editorial layouts and independent magazines.
- **Dark Mode Support**: Seamless transitioning between light and dark themes with system-level awareness.
- **Markdown Driven**: Content is generated entirely from local Markdown files with YAML frontmatter.
- **Responsive Layout**: Fluid "dual-column" metadata and typography scaling for all screen sizes.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Configuration

All global settings (author name, logo, typography) can be easily customized in `src/site.config.ts`.
